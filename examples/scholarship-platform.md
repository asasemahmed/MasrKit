# Scholarship application platform

```text
Use MasrKit's arabic-ui, arabic-rtl, egyptian-copy, egyptian-product-ux, and egyptian-backend skills.

Target: Egypt
Audience: Egyptian university students aged 18–25, primarily on phones.
Build: A scholarship discovery page and resumable multi-step application with document uploads and OTP sign-in.
Requirements: Arabic-first interface, English scholarship and university names preserved, progress saved on weak connections, accessible validation, clear file rules, and bilingual notifications.
Data: Normalize phone numbers for delivery, retain display input when useful, and store uploads privately.
```
