# Egyptian product terminology reference

This is a decision aid, not a mandatory translation table. Product domain, register, and user research take precedence.

| Concept | Neutral/formal | Professional Egyptian possibility | Notes |
|---|---|---|---|
| Mobile phone | رقم الهاتف المحمول | رقم الموبايل | `موبايل` is familiar but not right for every formal context |
| Send/submit | إرسال | ابعت | For applications, `إرسال الطلب` can prevent ambiguity |
| Save | حفظ | احفظ | Name draft behavior when relevant |
| Try again | حاول مرة أخرى | جرّب تاني | Pair with what failed |
| Not yet | ليس بعد / حتى الآن | لسه | Avoid dialect in high-formality policy copy |
| Sign in | تسجيل الدخول | ادخل على حسابك | Keep distinct from account creation |
| Create account | إنشاء حساب | اعمل حساب | State benefit before high-friction registration |
| Cart | سلة التسوق | السلة | Use one variant consistently |
| Order | طلب | أوردر only if research strongly supports it | `طلب` may also mean application/request; clarify context |
| Support | الدعم / خدمة العملاء | كلم خدمة العملاء | Do not promise channel availability |

For a project termbase, record rejected variants and why. A “common” term is not automatically best for accessibility, formal settings, or every Egyptian audience.
